# ChoralRoot FM-1 designer

Tools for designing M-VAVE FM-1 panel states (key and button LEDs, knob functions, 240×240 screen
mock-ups) and communicating them between the user and Claude. Sibling of the OMX-27 and monome grid
LED designers.

- `index.html` — **the designer**; open in a browser. Self-contained (no build/deps). Models the FM-1:
  **27 keys F3–G5** (index 0–26, MIDI 53 + index, one white LED each), **14 buttons** (`FX SEL ENV LFO
  EDIT GLO / HOME SAVE ARP SEQ PLAY REC / OCT- OCT+`, LED each; REC red, PLAY orange + a green
  transport LED), **8 rotaries** (`MASTER` pot, `SELECT PRESETS ALGORITHM KNOB1-4` encoders, no push),
  and the **240×240 screen** rendered from a structured description in Felucca's UI grammar and
  palettes. Paints LED levels 0–3, relabels controls (design-wide sticker + per-state layer labels),
  annotates, holds 1–24 states, exports faceplate and screen-sheet PNGs, saves/loads
  `fm1-panel-design` JSON.
- `FORMAT.md` — the `fm1-panel-design` JSON spec (version 1), including every screen panel template.
  **Read this before generating or interpreting a design.**
- `examples/choralroot-fm1-mockups.json` — the ChoralRoot FM-1 interface in 24 states. It is
  generated by `../ChoralRootFM1/design/make_mockups.py`; edit the generator, not the JSON, when the
  ChoralRoot design changes, then copy the output here.
- `tools/serve.py` — dev server with a `POST /save` endpoint; `?design=URL&export=screens|plate&post=/save`
  renders a design to `docs/` without a download dialog (see README).
- `docs/` — exported PNGs.

When the user asks for an FM-1 design, output a complete `fm1-panel-design` JSON (all 27 `keys`, all
14 `buttons`, the `encoders`, a `screen` per state) so they can load and inspect it, tweak it, and hand
back the modified JSON. Compute the LED arrays programmatically; rest every LED at level 1 (the glow).

## hardware reference (source of truth: Felucca's firmware for the FM-1)

- Key indexing, black keys, MIDI notes: `Felucca/firmware/src/seq.c` (`key_black`, `kb_map`: note = 53 + k).
- Button and encoder ids: `src/panel.c` (`B_*`, `EN_*`); LED matrix and the dim glow: `hal/fm1_input.h`.
- Screen layout and type sizes: `src/ui.c` (`Y_HEAD`, `CARD_X`, `Y_GRAPH`, `Y_FOOT`); palettes:
  `tools/gen_ui_palettes.py`. The geometry of the faceplate is measured from
  `MWaveFM1Reference/layout.png` (904×566 px, 0.1878 mm/px).
